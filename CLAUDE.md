# Project writing rules

- Never use em dashes (the U+2014 character) anywhere in this project: code, UI copy, content, seed data, prompts, docs, commit messages. Use a comma, colon, period or parentheses instead. `npm run lint:emdash` enforces this and runs before every build.
- Voice is collective ("we"), plain, confident, no hype words. Long Slow Distance is a crew, not a brand persona.
